# leonard_grid_assets

Lenny's grid assets for a the_grid station: the station-driven `selfdrive`
circuit (panel-harness daemon, outer driver, receipt verify) and its
capability registry. A station composes the pack beside `grid_assets`; the
circuit drives a Leonard-instrumented app toward a goal and verifies the
receipt.

Part of the [lenny](https://github.com/memento-engineering/lenny) workspace.
